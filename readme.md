- 各要素毎にサブディレクトリを作る（commonでも）

# ディレクトリ構成

- common ... 共通要素
  - constants ... 定数
  - element ... Reactエレメント
  - types ... 型定義（TypeScript）
  - utils ... ユーティリティ関数系
- features ... 機能ごとの要素
  - api
  - element ... Reactエレメント
  - types ... 型定義（TypeScript）
  - utils ... ユーティリティ関数系
  - route.ts ... ルーターが必要な場合
